## GitHub Pages
1. Create a new GitHub repository.
2. Upload all files from this folder to the `main` branch.
3. Open **Settings → Pages**.
4. Set the source to **GitHub Actions**.
5. Push/refresh the repository. The workflow deploys the site automatically.

## Android
This project is a mobile-friendly PWA and can be installed from a supported mobile browser using **Add to Home Screen / Install App** after GitHub Pages deployment.

For a standalone APK, wrap this deployed web app with a Trusted Web Activity/Android WebView project.
